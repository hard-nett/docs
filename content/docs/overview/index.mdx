## What Is Terp Network?
Terp Network is a **decentralized operating system for curating trustless, interoperable, and free markets**.

 Powered by a global market of providers running open source software, competing to curate tooling and services that most align to users, while consequently avoiding traditional censorship methods seen inside existing applications, services, and platforms.

### In 60 Seconds

Instead of using software and rails that are governened and controlled by a centralized entity, publishing and accessing content is able to occur with:

1. keys you generate and keep safe yourself 
2. sign and broadcast messages to a network you can run a node yourself
3. connect an integrate with 0 vendor lock-in
4. get rewarded passively for contributing 

# Architectural Overview

The nature of the software Terp Network *'speaks'*, supports a feature-dense ecosystem, that is interoperable with most of the current cryptocurrency ecosytems, extending functions that exists as an option for terpene loving communities to decide how to experiment, customize, and participate.
