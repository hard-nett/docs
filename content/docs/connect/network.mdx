## Common Workflow
1. `terpd init <moniker> --chain-id $CHAIN_ID`
2. Download genesis, update `config.toml` (seeds, peers), `app.toml` (gas prices: `0.05uthiol`)
3. Sync using snapshot or state-sync
4. Start node with `terpd start` or cosmovisor
5. Create validator tx if applicable

See [node guides](/guides/network/nodes) for full setup, hardware, and sentry configuration.
