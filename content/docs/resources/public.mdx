## S3 Bucket Structure

All resources are hosted on Terp Network's public S3 storage following this hierarchy:


<Files>
  <Folder name="s3.terp.network" defaultOpen disabled>
    <Folder name="snapshots" defaultOpen>

          <File name="assetlist.json" />
          <File name="chain.json" />
          <File name="genesis.json" />

          <File name="versions.json" />
        </Folder>
      </Folder>
      <Folder name="testnet">
        <Folder name="120u-1" defaultOpen>
          <File name="addrbook.json" />
          <File name="assetlist.json" />
          <File name="chain.json" />
          <File name="genesis.json" />
          <File name="snapshot_full.json" />
          <File name="versions.json" />
        </Folder>
      </Folder>
    </Folder>
  </Folder>
</Files>

If you prefer direct access, resources follow this pattern:

```bash
# Mainnet
https://s3.terp.network/snapshots/mainnet/morocco-1/{filename}

# Testnet  
https://s3.terp.network/snapshots/testnet/120u-1/{filename}
```
