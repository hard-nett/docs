## Network Specs

| Parameter | Mainnet (`morocco-1`) | Testnet (`90u-4`) |
|-----------|----------------------|-------------------|
| Validators | Up to 100 | Up to 50 |
| Block time | ~6s | ~6s |
| Unbonding | 21 days | 7 days |
| Governance period | 7 days | 3 days |
| Min fee | `0.05uthiol` | `0.05uthiol` |
